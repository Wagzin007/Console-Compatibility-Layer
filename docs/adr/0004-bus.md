# ADR 0004: Bus

- **Contexto:** Acesso à memória do console ocorre frequentemente e deve refletir o mapa de hardware sem confundi-lo com memória virtual do host.
- **Opções:** Interface virtual genérica no caminho de cada acesso; bus concreto e tipado para o GBA.
- **Decisão:** Usar uma classe concreta `GbaBus`, com acessos inline de 8, 16 e 32 bits e sem interface virtual no caminho crítico. O bus lógico do console é distinto da memória virtual do host.
- **Consequências:** A implementação pode especializar o mapa de memória do GBA e manter explícita a distinção entre os dois espaços de endereço.
- **Status:** Aceita.
