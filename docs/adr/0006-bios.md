# ADR 0006: BIOS

- **Contexto:** O boot do GBA pode depender de BIOS, mas o projeto não pode distribuir firmware proprietário.
- **Opções:** Exigir BIOS sempre; distribuir uma cópia; oferecer modos de inicialização alternativos.
- **Decisão:** Priorizar boot direto no estado pós-BIOS, permitir BIOS fornecida pelo usuário e implementar HLE incremental de SWIs e entrada de IRQ. Nunca distribuir BIOS.
- **Consequências:** O usuário controla a BIOS externa; os caminhos de boot poderão evoluir conforme a cobertura HLE.
- **Status:** Aceita.
